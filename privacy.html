SNACKY

プライバシーポリシー

Moeka Nagashima（以下「運営者」）は、アプリ「Snacky」（以下「本アプリ」）で扱う利用者の情報を、次のとおり扱います。本アプリにはアカウント登録がなく、氏名やメールアドレスは取得しません。

1. 取得する情報と保存する場所

情報内容保存する場所
学習記録学んだ単語、クイズの結果、復習の予定、連続学習、保存した単語や会話、目標やレベルなどの設定利用者の端末の中だけ
端末 ID本アプリが初めて起動したときに作るランダムな番号。端末の本来の ID や広告 ID ではありません端末と、運営者のサーバー
入力した内容辞書で調べた語、翻訳した文、質問、クイズの答え答えを作るためにサーバーを通して AI の提供元に送られます。運営者のサーバーには残しません
単語カード調べた単語の説明。誰が調べたかは結びつけません運営者のサーバー（全員で共有）
利用量端末 ID ごとの1日・1か月の利用量と回数、端末のタイムゾーン運営者のサーバー
IP アドレス不正な大量利用を防ぐための、1日ごとの回数運営者のサーバー
購入の状態有料プランや無料体験の状態、チャージの購入。クレジットカードなどの支払い情報は受け取りませんApple、RevenueCat、運営者のサーバー

2. 利用する目的

  1. 辞書、翻訳、質問、クイズなどの機能を提供するため
  2. 学習ペースの上限を管理し、不正な利用を防ぐため
  3. 有料プランやチャージの購入を確かめるため
  4. 不具合の調査と、本アプリの改善のため

3. 外部への提供

運営者は、次の場合を除き、利用者の情報を第三者に提供しません。提供先は、運営者から頼んだ仕事のためにだけ情報を使います。

提供先提供する情報目的所在国
Anthropic, PBC入力した内容と、学習のレベルなど答えを作るのに必要な情報AI による説明や翻訳を作るアメリカ
Supabase, Inc.端末 ID、利用量、IP アドレス、単語カードサーバーとデータベースの運用アメリカ
Apple Inc.購入の情報支払いと定期購入の管理アメリカ
RevenueCat, Inc.端末 ID、購入の状態有料プランの状態の管理アメリカ

法令により開示を求められた場合は、その範囲で提供することがあります。

4. 外国にある事業者への提供

上の提供先はアメリカの事業者です。アメリカには、日本の個人情報保護法と同じ内容の、国全体の個人情報保護の法律はありません。運営者は、各提供先の利用規約やデータの取り扱いの定めで、情報が適切に守られていることを確かめています。Anthropic は、API で受け取った内容を、原則として AI の学習に使わないと定めています。

5. 保存する期間と削除

  1. 端末の中の学習記録は、本アプリを削除すると消えます。
  2. サーバーの利用量と IP アドレスの記録は、90日を過ぎたものから削除します。
  3. 単語カードは、誰が調べたかと結びついていないため、削除の対象にはなりません。
  4. 端末 ID にひもづく記録の削除を希望するときは、問い合わせ先にご連絡ください。

6. 広告と追跡

本アプリは広告を表示せず、ほかの会社のアプリやウェブサイトをまたいで利用者を追跡しません。解析ツールも使っていません。

7. 通知

学習のお知らせは、端末の中で予定を組んで出しています。通知のために情報をサーバーに送ることはありません。

8. 子どもの利用

16歳未満の方は、保護者の同意を得てから本アプリを使ってください。翻訳や質問に、自分や他人の個人情報を入力しないでください。

9. 開示・訂正・利用停止の求め

利用者は、運営者が持つ自分の情報の開示、訂正、利用の停止、削除を求めることができます。問い合わせ先にご連絡ください。本人であることを確かめるため、アプリのマイページの「設定」に表示される端末 ID をお知らせいただくことがあります。

10. 安全のための対策

サーバーとの通信は暗号化しています。サーバーのデータには、運営者のサーバーの処理だけが触れるようにしています。

11. このポリシーの変更

内容を変えるときは、本アプリまたは公式サイトでお知らせします。
